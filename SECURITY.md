# SECURITY.md

## Supported Versions
| Version | Supported |
| --- | --- |
| Latest release (Windows Desktop) | Yes |
| Older releases | No (upgrade recommended) |

## Reporting a Vulnerability
If you discover a security vulnerability in this fork, please report it responsibly:

1. **Do not** open a public GitHub issue with exploit details.
2. Email the maintainer privately via GitHub (contact through the repository owner) with:
   - A description of the vulnerability and affected component (Windows Desktop/Android/Android TV)
   - Steps to reproduce
   - Potential impact
   - Suggested fix if available

We will acknowledge receipt and work to assess and address valid reports.

## Responsible Disclosure
- Avoid testing against production services or other users' data
- Do not exfiltrate data or escalate privileges beyond proof of concept
- We aim to coordinate disclosure after a fix is available

## Notes
This is a fork of [NewPipe](https://github.com/TeamNewPipe/NewPipe). Security issues may also need to be reported upstream if they affect shared components.
